# Workshop 01: Agentic AI for GTM Programs (45 minutes)

**Audience:** Business leaders and GTM managers (AMER)  
**Goal:** Leave with a shared vocabulary for agentic AI in GTM programs, plus one baseline you can write this week.  
**Facilitator note:** Use fictional accounts only (Acme Energy, Northwind Retail).

## Agenda

| Minutes | Block | Outcome |
|--------:|-------|---------|
| 0-5 | Open | Why baselines beat slogans |
| 5-15 | Concepts | Agents, tools, skills, evals in plain language |
| 15-25 | Live pattern | Walk a program plan shape (name, baseline, metrics, owners, milestones) |
| 25-40 | Exercise | Draft a program baseline (see `exercises/exercise_baseline.md`) |
| 40-45 | Close | 30-day measurement commitment |

## Teaching points

1. **Agentic GTM is not "chat in Slack."** An agent follows instructions, may call tools, and should be checked with evals.
2. **Programs need a baseline before launch.** Without a start state, attribution reviews become storytelling.
3. **Skills are reusable GTM workflows.** Examples in this repo: program baseline, seller play packager, attribution review, discovery coach, enablement outline.
4. **Measure adoption, not applause.** Leading metric: practice completion. Lagging metric: play logged on qualified opportunities.
5. **Evals catch weak plans offline.** Rubric dimensions: baseline clarity, measurable metrics, named owners, no fluff.

# Exercise: Set a Program Baseline

**Time:** 15 minutes  
**Work alone or in pairs**

## Scenario (fictional)

You are launching an AMER mid-market discovery play. Example accounts for talk tracks: Acme Energy and Northwind Retail. CRM does not yet have a "discovery checklist complete" field.

## Task

Fill this template. Do not invent win rates or pipeline dollars. Use TBD with a named owner when data is missing.

```
Program name:
Audience / geo:
Launch date:

Primary success metric:
  unit:
  source system:
  baseline value (or TBD + who fills it):
  owner:

Supporting metric 1:
Supporting metric 2:

Scope in:
Scope out:

Owners:
  Program:
  Sales sponsor:
  Enablement:
  Analytics:

30-day definition of done:
90-day definition of done:

Open gaps:
```

## Done when

- Primary metric is measurable or explicitly TBD with an owner
- Four owner roles are named (roles are fine)
- At least one open gap is listed honestly

## Debrief (facilitator)

Compare two baselines. Prefer the one with clearer measurement and named owners over the one with bigger claims.

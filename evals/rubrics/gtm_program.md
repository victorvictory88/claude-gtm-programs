# GTM Program Plan Rubric

Score each dimension 0 (fail), 1 (partial), or 2 (pass). Offline harness sums dimensions.

## Dimensions

### baseline_clarity
- 2: Current state is explicit; unknowns marked TBD with a path to fill them
- 1: Baseline mentioned but vague or missing scope
- 0: No usable baseline

### measurable_metrics
- 2: Primary and supporting metrics include unit/source (or explicit TBD + source plan)
- 1: Metrics named without measurement detail
- 0: No metrics or only slogans

### named_owners
- 2: Program, sales sponsor, enablement, and analytics owners named (roles OK)
- 1: Some owners missing
- 0: No owners

### no_fluff
- 2: Concrete language; no empty slogans; no invented customer metrics
- 1: Some vague phrases but plan still usable
- 0: Mostly fluff or fabricated numbers

## Pass bar

Total >= 6 out of 8 and no dimension scored 0.
